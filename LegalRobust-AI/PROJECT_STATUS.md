# Project status

Implemented in this starter release:
- JSON case loading and schema validation
- LLM-assisted draft case generation
- OpenAI-compatible Chat Completions client
- Batch execution with per-case error capture
- Heuristic diagnostic scores and optional model judge
- Pair ID diagnostics
- JSON, CSV, and HTML exports
- Unit tests for core behavior

Not implemented / requires extension:
- Retrieval against official legal databases
- Verified statute/case citation checking
- GUI dashboard
- Distributed concurrency and provider-specific token accounting
- Expert-adjudicated gold benchmark
- Cryptographic audit trail

No live model requests were made when this package was created. The sample reports are not populated with invented model outputs.
